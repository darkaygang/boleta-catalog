# BDV / ARCHIVE — Branding + UI/UX Reference Pack

## Purpose
This pack is the visual source of truth for rebuilding the BDV made-to-order streetwear catalog as a premium underground/editorial storefront.

## Brand direction
- Underground streetwear
- Graffiti / metal / cyber-grunge influence
- Premium but raw
- Editorial / archive / collector feel
- Purple should be an accent, not a purple-filled dashboard
- Strong contrast, generous negative space, hard borders, subtle texture
- The logo itself stays visually untouched; do not redraw or "modernize" it

## Core concept
**BDV / ARCHIVE**
**PIEZAS QUE NO VES EN CUALQUIER LADO.**

Supporting line:
STREETWEAR · JWLRY / JEWELRY · EYEWEAR · OBJECTS

Primary commercial concept:
Products are **POR ENCARGO**. The website is a showroom/catalog and lead-conversion experience, not a conventional instant-checkout ecommerce store.

## UX vocabulary
Use **MI PEDIDO** instead of a generic "carrito".
Use **AÑADIR AL PEDIDO** instead of "Comprar ahora" where appropriate.
Primary conversion should be **ENVIAR POR WHATSAPP**.

## Typography
Preferred:
- Manrope for UI, product names, prices and headlines
- DM Mono for metadata, codes, labels and technical/editorial details

## Target experience
1. Hero: brand statement + CTA.
2. Catalog: filters, search, sorting, clean product grid.
3. Product quick view/full detail: large imagery, sizes/variants, price, made-to-order status.
4. Order drawer: "MI PEDIDO" with quantity editing and estimated total.
5. WhatsApp handoff: prefilled message containing selected items and variants.
6. "Cómo funciona el encargo": Eliges → Confirmamos → Reservas → Recibes.
7. Footer: minimal brand/editorial close.
